# Rcasani Matrícula

Sistema de gestión de matrícula universitaria basado en una arquitectura de microservicios.

## Arquitectura

- API Gateway
- Eureka Server
- Saga Orchestrator
- Alumno Service
- Curso Service
- Horario Service
- Vacantes Service
- Pago Service
- Matrícula Service
- Notification Service
- Reporte Service
- Apache Kafka

## Tecnologías

- Java 21
- Spring Boot
- Spring Cloud
- Spring Data JPA
- PostgreSQL
- MongoDB
- Apache Kafka
- Docker
- Git
- GitHub
